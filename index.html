Mirage Centers

Mirage Centers is a low-tech static web page by William Jourdain, the Canadian artist working under the moniker of Automatisme. Each day, one generative audiovisual piece is selected from a limited set.

Built from archival recordings of data centers, this work turns the physical cloud into a frugal and sustainable environment.

Artwork compression used here reduces file size by around 90%, and minimizes the energy required to run this micro-ecosystem.

One configuration per day. No feed. No catalogue. Limited resources. Deliberate playback.

Mirage Centers enters sleep mode at night. Why should the internet be online 24/7?
